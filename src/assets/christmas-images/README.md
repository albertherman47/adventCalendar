# Christmas image assets

Add your Christmas photos or illustrations to this folder (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, or `.gif`).

Vite picks them up automatically on the Printable Resources page: the first image by filename is used in the large header, and the images are rotated through the printable cards. No code changes are needed when adding images.

Use images you have permission to use. A landscape image around 1400 × 900 px works well for the header; card images are cropped to a wide landscape frame.
